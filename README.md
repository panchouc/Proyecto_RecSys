El repositorio tiene 2 ramas principales:

- `data_analysis`: Contiene los scripts y notebooks utilizados para el análisis de datos, incluyendo limpieza, transformación y visualización de datos. El archivo principal es `main.py`. Se debe ejecutar este archivo para reproducir el análisis de datos. `plotting.py` contiene las funciones de visualización utilizadas en el análisis.
- `modelos_ref`: Contiene los 4 modelos de referencia utilizados. El archivo principal es `modelos_referenciales.ipynb`.
